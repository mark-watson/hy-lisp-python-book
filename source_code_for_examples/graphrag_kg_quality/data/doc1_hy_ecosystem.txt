Mark L. Watson developed a suite of knowledge graph and retrieval applications in the Hy Lisp language.
Mark L. Watson created zvec_RAG to demonstrate local retrieval-augmented generation in Hy.
Mark Watson also designed KG-Creator as an automated pipeline that turns raw text files into RDF triples.
Every project in the suite runs on Python 3.12+ using Hy 1.3.1 S-expressions and pytest test suites.
